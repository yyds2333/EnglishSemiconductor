# ADR-004：安装、升级与数据目录

## 状态

候选基线，进入安装器实现

## 决策

1. 发布目标固定为 Windows 11 x64，应用使用 `win-x64` 自包含发布，不要求用户预装 .NET Desktop Runtime。
2. MVP 安装方式采用 per-user 安装，不要求管理员权限；安装器只写入用户选择的应用目录和当前用户的开始菜单/桌面快捷方式。
3. 安装器实现候选为 Inno Setup x64；安装脚本、版本号和卸载行为纳入版本库，实际生成安装包前复核工具链和签名环境。
4. MVP 不做静默自动更新。用户手动运行新安装包覆盖升级；升级前保留数据库，失败时不得删除旧版本应用和用户数据。
5. 用户数据与程序文件分离：`%LOCALAPPDATA%\\WordPin\\wordpin.db` 为学习数据库，`dictionary\\` 为版本化只读词典库，`backups\\` 为备份，`logs\\` 为诊断日志。
6. 卸载默认保留用户数据；设置页提供显式的清除入口。清除操作必须二次确认并可在执行前生成备份。
7. 代码签名暂不伪造状态。正式公开发布前必须使用受信任的代码签名证书签署安装器和主程序，并在 CI 中验证签名；内部开发构建可以保持未签名。

## 约束与验收

- 安装包只能包含 x64 产物，不生成 x86/ARM64 安装包。
- 全新安装、覆盖升级、卸载后重装均不得意外覆盖学习数据库。
- 应用无写入安装目录的依赖；数据库迁移和词典升级使用临时文件、校验和原子替换。
- 在 Windows 11 24H2、25H2 和可用的 26H1 x64 环境完成安装/启动/升级回归。

## 未决事项

- 最终 Inno Setup 版本和安装包主题。
- 证书供应商、签名时间戳服务和 CI 秘钥托管。
- 是否在后续版本加入应用内更新检查。

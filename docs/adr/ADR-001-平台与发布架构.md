# ADR-001：平台与发布架构

## 状态

已接受

## 日期

2026-08-25

## 背景

WordPin需要置顶窗口、全局快捷键、系统托盘、开机启动、多显示器位置恢复和本地文件访问。产品负责人已明确只需要Windows 11 x64，不需要Windows 10、x86或ARM64。

## 决策

- 正式支持平台为 Windows 11 x64。
- 最低运行基线为 Windows 11 24H2，OS build 26100。
- 主发布测试环境为 Windows 11 25H2 x64。
- 对 Windows 11 26H1 x64执行兼容性测试，但不依赖26H1专属能力。
- 只生成 `win-x64`运行时和安装包。
- 应用默认以自包含方式发布，不要求用户另行安装.NET运行时。
- 默认采用每用户安装，不要求管理员权限；最终安装器在 ADR-004 中确认。

## 影响

- 不为Windows 10兼容性投入测试或代码分支。
- 不生成x86和ARM64产物。
- 所有发布说明必须列明最低Windows build和x64要求。
- 如果最低支持版本需要提升，必须通过ADR和迁移说明记录。

## 未决事项

- 具体安装器技术和自动更新方式由 ADR-004 决定。
- 代码签名证书和发布渠道尚未采购或配置。

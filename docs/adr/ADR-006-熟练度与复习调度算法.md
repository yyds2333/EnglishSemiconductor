# ADR-006：熟练度与复习调度算法

## 状态

已接受工程基线，产品参数仍可在实现验收时调整

## 背景

初始规格中的固定加分、间隔倍率和随机扰动可能产生反直觉结果：用户连续选择 EASY 时，达到 L5 的时间反而晚于连续选择 GOOD。算法还需要区分实际经过时间、成功回忆证据和下次复习时间。

## 决策目标

- 对相同历史，EASY 的下次间隔不短于 GOOD。
- 对同质序列，EASY 达到同一等级的时间不晚于 GOOD。
- AGAIN 明确降低稳定性并清除连续成功记录。
- L4/L5 必须经过跨日验证，不能在一天内刷出。
- 相同输入产生相同输出，不在 MVP 使用随机扰动。
- 历史复习事件保留，算法状态可从事件重算。

## 候选状态

每个单词保存或由复习事件聚合得到：

- `stability_days`：记忆稳定性估计，单位为天。
- `interval_days`：当前复习间隔；AGAIN可以为0.006944天（10分钟）。
- `evidence_points`：成功回忆证据点数，允许0.5步进。
- `lapse_count`：AGAIN累计次数。
- `success_streak`：连续HARD/GOOD/EASY次数。
- `first_reviewed_at`、`last_reviewed_at`、`next_review_at`。
- `mastery_score`：0～100展示分数。
- `mastery_level`：L0～L5离散等级。
- `algorithm_version`：本次计算使用的算法版本。

## 反馈权重

| 反馈 | 证据点 | 稳定性更新 | 间隔更新 |
|---|---:|---|---|
| AGAIN | +0 | `max(0.25, old × 0.25)` | 10分钟 |
| HARD | +0.5 | `max(1, old × 1.2)` | `max(1天, old间隔 × 1.2)` |
| GOOD | +1 | `max(2, old × 2.0)` | `max(2天, old间隔 × 2.0)` |
| EASY | +1.5 | `max(4, old × 2.0)` | `max(4天, old间隔 × 2.0)` |

首次复习使用“old=0”的最小值；后续复习使用当前值。所有间隔最大为180天。MVP不加入随机抖动；如果未来需要错峰，使用队列层的展示顺序，不改变单词的真实到期时间。

## 掌握度分数

```text
mastery_score = clamp(
    round(stability_days × 2 + min(evidence_points, 5) × 8 - lapse_count × 6),
    0,
    100
)
```

分数只用于展示和等级条件，不直接替代复习事件。`evidence_points`使用整数十分位保存，例如1.5点保存为15，避免浮点累计误差。

## 等级判定

每次复习后按高等级到低等级判定：

1. L5：`score >= 88`、`stability_days >= 21`、`evidence_points >= 5`，并且从首次复习到当前至少经过21天。
2. L4：`score >= 70`、`stability_days >= 7`、`evidence_points >= 3`，并且从首次复习到当前至少经过7天。
3. L3：`score >= 45`。
4. L2：`score >= 25`。
5. L1：有复习记录但低于L2条件。
6. L0：没有有效复习记录。

如果上一次等级为L4且本次反馈为AGAIN，结果等级不得高于L3；如果上一次等级为L5且本次反馈为AGAIN，结果等级不得高于L4。连续两次AGAIN额外扣8分，并再次应用降级上限。

“待抽查”是派生状态：超过`next_review_at` 30天且没有新的复习事件时显示，不自动降低等级。

## 时间规则

- 所有时间点以UTC存储。
- `actual_elapsed_days = max(0, reviewed_at - last_reviewed_at)`。
- 7天和21天验证使用从首次复习到当前的实际经过时间，不使用计划间隔。
- AGAIN的10分钟重试按绝对时间计算，不向整天取整。
- 其他间隔以实际小时数计算，界面按用户本地时区显示预计时间。
- 提前复习不获得“足额间隔”奖励；稳定性仍按反馈更新，但额外证据奖励只在实际间隔达到上次计划间隔的80%时生效。

## 事件记录要求

每个复习事件必须保存：

- 反馈、复习前后分数和等级。
- 复习前后稳定性、证据点、间隔和连续成功次数。
- `scheduled_due_at`、`actual_elapsed_days`和`reviewed_at`。
- `session_id`、`queue_reason`和`algorithm_version`。
- 是否使用额外提示。

## 必须通过的模拟不变量

- 连续GOOD和连续EASY均能达到L4和L5。
- 连续EASY达到相同等级的时间不晚于连续GOOD。
- 连续AGAIN不会提高分数、稳定性或等级。
- L4/L5不会在首次复习当天产生。
- 相同事件序列重复计算结果完全一致。
- 算法版本变化不会修改旧复习事件。

## 未决事项

- 产品负责人是否接受“EASY=1.5证据点”的解释。
- 是否在P1加入拼写/填空等客观题，并单独记录客观正确率。
- 是否在P1增加可配置的复习强度。

# ADR-003：词典数据源与隐私

## 状态

候选基线，进入实现前的许可复核

## 背景

WordPin需要中文释义、英文释义、词性、音标、词形变化和发音。产品又要求本地优先、允许离线收词，并且默认不上传用户的单词、原句或来源路径。单一在线API无法同时满足离线能力、成本、隐私和缓存要求。

## 调研结论

### ECDICT：本地中文释义主源

ECDICT是英文到中文的双解词典数据库，公开仓库说明提供英文释义、中文释义、词性、词形变化和词频等字段；仓库内同时提供MIT许可证文件和数据来源说明。项目使用时必须保留上游版权/许可证文件，并在应用的第三方声明中注明来源。数据来源复杂，公开发布前仍需进行一次人工许可复核，不把“代码仓库为MIT”自动等同于所有上游词条内容均无额外权利要求。

### Free Dictionary API：可选在线补充

Free Dictionary API的公开接口提供英文释义、词性、音标、例句和部分音频地址，适合作为缺词、音频和英文释义的补充。MVP只在用户允许网络查询时调用；查询失败不影响本地收词。原始接口内容是否可长期缓存必须按其最新服务说明复核，默认只缓存已规范化且产品确实需要的字段。

### 有道词典 API：不作为默认源

有道词典官方文档说明其返回数据严禁缓存、再利用和转卖。WordPin的本地优先设计需要保存用户可复习的释义，因此不把有道词典作为默认提供器。未来如用户自行配置并接受服务条款，可以作为“实时查询、不落库”实验提供器，但不得混入默认缓存流程。

## 决策

1. 词典业务层只依赖 `IDictionaryProvider` 接口，UI不得直接调用服务。
2. MVP的中文释义优先来自本地 ECDICT 数据包。
3. ECDICT数据包不直接提交到主代码仓库；通过版本化下载/导入脚本生成本地SQLite词典库，并保留来源版本、下载地址、校验值和许可证文件。
4. 英文释义、音标和发音优先使用本地数据；缺失时可在用户开启在线查询后调用 Free Dictionary API。
5. 在线查询默认只发送用户主动触发的单词或短语，不发送原句、备注、来源应用或文件路径。
6. 在线结果只在许可允许范围内缓存；缓存字段和缓存期限由每个提供器明确声明。
7. 用户可以关闭所有网络查询；关闭后应用继续使用本地词典和手动编辑。
8. 当本地词典没有结果时，界面显示“未找到本地释义”，不假装已完成查询。

## 提供器接口约束

```csharp
public interface IDictionaryProvider
{
    string ProviderId { get; }
    bool IsOnline { get; }
    bool CanCacheNormalizedFields { get; }

    Task<DictionaryEntry?> LookupAsync(
        string term,
        string language,
        CancellationToken cancellationToken);
}
```

每个提供器必须返回来源标识、查询时间、缓存策略和许可备注。查询结果写入用户词库前必须经过字段映射和长度限制，不直接持久化第三方原始JSON。

## 数据包策略

- 使用独立下载脚本获取指定版本 ECDICT 数据。
- 下载后校验SHA-256。
- 转换为只读SQLite词典库，用户学习数据库与词典数据库分离。
- 词典数据库升级失败时保留旧版本。
- 应用启动时只加载词典索引，不将全部词条读入内存。
- 第三方声明页面显示词典版本、来源链接、许可证和本地修改说明。

## 隐私与网络设置

设置页提供：

- 允许在线补充查询：默认关闭或由首次启动引导明确询问。
- 允许音频在线加载：默认开启但可关闭。
- 清除在线缓存。
- 查看本次查询发送的字段说明。

## 未决事项与出口条件

- 完成指定ECDICT版本的许可和数据来源人工复核。
- 选定Free Dictionary API的缓存边界并在代码中固化。
- 完成本地词典下载、校验、转换和升级失败回滚技术验证。
- 在没有网络和没有词典数据包两种情况下，收词流程仍然可保存占位记录。

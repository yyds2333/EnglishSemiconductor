# ADR-002：工程技术栈

## 状态

暂定，S0待确认

## 背景

应用只面向Windows，需要稳定支持置顶、托盘、全局快捷键、DPI和多显示器行为。应用还需要本地SQLite数据和可测试的领域逻辑。

## 候选方案

1. .NET 10 + WPF + C#。
2. .NET 10 + WinUI 3 + C#。
3. Tauri + Web UI。

## 当前选择

暂定使用 .NET 10 + WPF + C# + SQLite：

- WPF直接适合Windows桌面窗口、数据绑定和成熟的桌面控件模型。
- C#和.NET提供稳定的本地文件、任务、时间和测试工具链。
- SQLite适合单用户本地优先数据。
- 领域层与UI层可以严格分离，熟练度算法可独立测试。

## 工程结构

```text
WordPin.App              WPF窗口、资源和ViewModel
WordPin.Application      用例、队列、服务接口
WordPin.Domain            实体、值对象、学习规则
WordPin.Infrastructure    SQLite、词典、Windows集成、备份
WordPin.Tests             单元和集成测试
```

## 接受前必须验证

- `win-x64`自包含构建。
- Windows 11 24H2/25H2核心窗口行为。
- 单实例、托盘、快捷键和DPI。
- 构建警告即错误和测试覆盖率入口。

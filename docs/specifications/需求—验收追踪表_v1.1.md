# WordPin v1.1 需求—验收追踪表

本表将当前规格中的关键需求映射到验收场景和实现模块。新增P0需求必须同时增加一条追踪记录。

| 需求域 | 需求标识/规则 | 主要实现层 | 验收场景 |
|---|---|---|---|
| 平台 | Windows 11 x64，最低build 26100 | App/Installer | AT-201、AT-205、发布安装冒烟 |
| 悬浮窗 | 置顶、折叠、位置恢复、DPI | App/WindowsIntegration | AT-201～AT-204 |
| 收词 | 复制后快捷键，一次读取剪贴板 | Application/WindowsIntegration | AT-001、AT-005 |
| 文本清洗 | Unicode、大小写、连字符、短语 | Domain | AT-004及同形词回归 |
| 去重 | 词义区分键、词形关联、可撤销合并 | Domain/Infrastructure | AT-002及同形词回归 |
| 离线保存 | 先保存占位记录，再查询 | Infrastructure | AT-003 |
| 本地词典 | ECDICT版本、校验、SQLite索引 | Infrastructure/Tools | 词典导入测试 |
| 在线补充 | 可关闭、最小发送字段、缓存边界 | Infrastructure | 网络隐私测试 |
| 熟练度 | ADR-006确定性算法 | Domain | AT-101～AT-107、算法模拟器 |
| 复习会话 | 快照、互斥分类、AGAIN重试 | Application/Infrastructure | 队列一致性测试 |
| 进度统计 | 成功回忆率、净掌握量口径 | Application/UI | 统计口径测试 |
| 数据库 | 迁移、事实事件、聚合状态 | Infrastructure | AT-301～AT-304 |
| 备份 | Backup API/VACUUM INTO、一致性校验 | Infrastructure | 备份故障注入 |
| 隐私 | 不持续监听剪贴板、日志脱敏 | App/Infrastructure | 隐私回归 |
| 发布 | 自包含win-x64、升级不丢数据 | Installer/Release | 发布准入测试 |

## 追踪规则

- 需求状态以规格书 v1.1 和对应 ADR 为准。
- 验收场景通过前不得将需求标记为 DONE。
- 只有文档更新不代表功能完成；必须有代码和测试证据。
- 对第三方数据源，许可证复核是发布准入条件，不是普通文档任务。

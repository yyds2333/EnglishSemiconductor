## 1. 文档目的

本规格书定义 WordPin MVP 的产品范围、交互流程、业务规则、数据模型、技术建议、验收标准和版本计划。设计、开发和测试人员应以本文档作为当前实现依据。

本文档中的“必须”表示 MVP 必须实现；“建议”表示允许根据工期延后；“暂不实现”表示不应进入 MVP 范围。

## 2. 产品定义

WordPin 是一个可固定在 Windows 桌面前台的单词收集与复习工具。用户在浏览网页、阅读 PDF、观看课程或编写代码时，可以通过输入、粘贴或全局快捷键快速收录生词。应用保存单词释义及其出现上下文，并通过分级熟练度和间隔复习帮助用户了解真实学习进度。

### 2.1 核心价值

1. 用户不离开当前学习页面即可完成收词。
2. 收录一个普通英文单词的操作时间不超过 2 秒，不含网络查询时间。
3. 应用区分“已收录”“眼熟”“会回忆”和“已稳定掌握”。
4. 每日任务按遗忘风险动态生成，不设置固定的 12 词上限。
5. 用户可以随时查看总量、各熟练度数量、净掌握量和复习完成情况。

### 2.2 目标用户

- 经常在 Windows 电脑上阅读英文网页、PDF、代码或课程资料的学习者。
- 希望随手收词，但不想频繁切换到词典或背单词软件的用户。
- 需要掌握个人学习进度，而非只统计收藏数量的用户。

### 2.3 MVP 成功指标

| 指标 | 目标 |
|---|---:|
| 本地查询的悬浮窗响应时间 | P95 小于 300 ms |
| 普通收词交互步骤 | 不超过 2 个动作 |
| 数据保存成功率 | 99.9% 以上 |
| 应用异常退出后的已提交数据丢失 | 0 条 |
| 置顶功能在支持的 Windows 版本中有效 | 100% 核心测试用例通过 |
| 首次用户完成“收词—复习—查看进度”闭环 | 无需阅读外部帮助文档 |

## 3. 产品范围

### 3.1 MVP 必须实现（P0）

- 置顶悬浮窗：展开、折叠、拖动、缩放、透明度、记忆位置。
- 系统托盘：显示/隐藏、切换置顶、开始复习、退出。
- 全局快捷键呼出悬浮窗并读取当前剪贴板文本。
- 手动输入、粘贴、剪贴板收录英文单词。
- 单词格式清洗、重复检测、重复遇见次数累计。
- 在线词典提供器接口；查询成功后保存音标、词性、释义和发音地址。
- 查询失败时允许先保存单词和上下文，稍后重试。
- 保存原句、来源标题、来源应用、来源地址或文件路径（可取得时）及备注。
- L0～L5 熟练度、0～100 掌握度、用户自评和“待抽查”状态。
- 四档复习反馈、自动升级/降级、动态每日队列。
- 单词列表、搜索、筛选、排序和详情编辑。
- 学习进度面板。
- CSV、JSON 导出；数据库自动备份和恢复。
- 开机启动开关、快捷键设置、隐私设置。

### 3.2 首版增强（P1，可在 MVP 稳定后实现）

- 拼写题、例句挖空题。
- 识别、回忆、运用三个能力维度。
- Anki 导出。
- 批量导入 CSV。
- 自动获取当前浏览器页面标题和地址。
- 深色模式。
- 鼠标穿透模式。
- 多词批量拆分和候选词选择。

### 3.3 暂不实现（P2）

- OCR 截图识词。
- 云同步、账号系统和移动端。
- AI 自动生成例句、文章或题目。
- 自动持续监听全部剪贴板内容。
- 社交排行榜、打卡分享。
- 完整词典编辑和自建词典社区。

## 4. 名词定义

| 名词 | 定义 |
|---|---|
| 收词 | 创建新单词记录，或为已存在单词新增一次遇见记录 |
| 遇见记录 | 单词在某个时间、句子、网页或文件中被用户遇到的上下文 |
| 到期词 | `next_review_at` 早于或等于当前时间的单词 |
| 掌握度 | 0～100 的规则评估分数，用于表达记忆稳定程度；MVP不代表客观考试成绩 |
| 熟练度 | L0～L5 的离散等级，由掌握度、实际经过时间和成功回忆证据共同决定 |
| 用户自评 | 用户主观设置的熟悉程度，不直接替代系统熟练度 |
| 稳定掌握 | 满足 L5 条件，且通过至少21天跨度的多次成功回忆；不称为客观验证 |
| 待抽查 | 超过下次复习时间30天仍未复习的单词；该状态不自动降级 |
| 复习事件 | 用户完成一张卡片后产生的答题结果记录 |

## 5. 信息架构

应用包含两个主要窗口。

### 5.1 悬浮窗

用于快速收词、查看简要释义、播放发音和进入复习。

### 5.2 主窗口

包含以下一级导航：

1. 今日
2. 单词库
3. 复习
4. 进度
5. 设置

系统托盘不是独立页面，但提供常用入口。

## 6. 核心用户流程

### 6.1 快速收词流程

快速收词要求用户先复制选区，再按快捷键；MVP不向其他应用模拟发送 `Ctrl+C`。

1. 用户在任意应用中选中英文单词或短语并复制。
2. 用户按全局快捷键，默认 `Ctrl+Shift+D`。
3. WordPin 一次性读取剪贴板并建立本地记录；结果提示不得持续抢占当前应用焦点。
4. 系统清洗文本并识别单词。
5. 如果单词不存在，系统立即建立本地占位记录并开始查询词典。
6. 查询成功后显示音标、首条常用释义和发音按钮。
7. 系统自动保存；用户可以补充原句、标签和备注。
8. 快速收词模式在无操作 5 秒后保持显示，不自动抢夺焦点；用户可手动折叠。

手动输入模式直接呼出并激活悬浮窗输入框，适用于剪贴板为空或需要编辑短语的情况。

验收要求：第 3 步到本地记录建立完成的 P95 时间小于 300 ms。

### 6.2 重复单词流程

1. 系统按规范化文本、语言、词义区分键和用户确认的词形关联查找记录。
2. 只有确认属于同一词义时才复用原学习项；同形词可以建立多个学习项。
3. 复用学习项时将 `encounter_count` 加 1，并新增遇见记录。
4. 悬浮窗显示“再次遇到，第 N 次”。
5. 如果该词为 L4 或 L5，系统添加“近期再次遇到”信号，但不直接降低等级。

### 6.3 每日复习流程

1. 用户进入“今日”或点击托盘中的“开始复习”。
2. 系统按队列规则生成今日任务。
3. 卡片正面显示单词，默认要求用户主动回忆中文含义；MVP结果属于自评回忆反馈。
4. 用户点击“显示答案”后查看音标、释义、原句和发音。
5. 用户选择“完全不会”“想起来了”“认识”“太简单”。
6. 系统保存复习事件，更新掌握度、熟练度、复习间隔和下次复习时间。
7. 页面即时显示本次规则评估分数变化和简短原因，不使用“客观考试正确”措辞。
8. 完成计划后，用户可选择“再学 10 个”或结束。

### 6.4 查看学习进度流程

1. 用户进入“进度”。
2. 默认显示最近 7 天数据。
3. 用户可切换 30 天、90 天和全部。
4. 用户可点击任意等级或标签进入对应单词列表。

## 7. 功能规格

## 7.1 悬浮窗

### 7.1.1 窗口行为

| 编号 | 要求 | 优先级 |
|---|---|---|
| FW-001 | 窗口支持“始终置顶”开关，默认开启 | P0 |
| FW-002 | 支持拖动并记住最后位置 | P0 |
| FW-003 | 支持宽度 280～600 px，高度 72～600 px | P0 |
| FW-004 | 支持折叠为不大于 56×56 px 的浮标 | P0 |
| FW-005 | 支持 40%～100% 透明度，默认 95% | P0 |
| FW-006 | 重启后恢复显示器、位置、尺寸、透明度和折叠状态 | P0 |
| FW-007 | 显示器断开时，将窗口移回当前主屏可见区域 | P0 |
| FW-008 | 支持鼠标穿透；进入后通过快捷键退出 | P1 |
| FW-009 | 悬浮窗不得持续强制抢占当前应用焦点 | P0 |

### 7.1.2 展开态内容

- 搜索/输入框。
- 保存状态：查询中、已保存、查询失败。
- 单词原形。
- 音标和发音按钮。
- 第一词性及最多两条常用释义。
- 熟练度徽标，例如“L3 基本掌握”。
- 掌握度，例如“62/100”。
- 再次遇见次数。
- 展开详情、添加备注、开始复习按钮。

### 7.1.3 文本清洗规则

按以下顺序处理：

1. 去除首尾空白。
2. 将弯引号、全角标点转换为可识别形式。
3. 去除短语首尾标点，保留内部连字符、撇号和空格。
4. 使用 Unicode 大小写折叠生成 `normalized_term`，同时保留原始大小写 `display_term`。
5. 连续空白压缩为一个空格。
6. 输入不超过 100 个字符时允许保存为单词或短语；超过100个字符转入候选词提示。
7. 空字符串、纯数字和纯标点不得保存。
8. `US/us`、`Polish/polish`等大小写敏感或同形词不得被不可逆自动合并。

MVP不以 `normalized_term + language` 作为唯一学习项。系统保存词义区分键和词形关联：同一拼写可以对应多个学习项；`learn/learned/learning`可以关联到同一词元，但不得覆盖用户原始输入。合并和拆分必须是可撤销的用户操作。

## 7.2 单词查询

### 7.2.1 查询结果字段

- 单词原形 `lemma`
- 英式音标 `phonetic_uk`
- 美式音标 `phonetic_us`
- 英式发音地址 `audio_uk_url`
- 美式发音地址 `audio_us_url`
- 词性 `part_of_speech`
- 中文释义 `definition_zh`
- 英文释义 `definition_en`
- 例句 `example`
- 查询提供器和查询时间

### 7.2.2 提供器规则

- 业务层必须通过 `DictionaryProvider` 接口访问词典，禁止让界面直接调用第三方 API。
- API 密钥不得硬编码到客户端仓库。
- 本地缓存命中时优先使用缓存。
- 同一个词在 24 小时内查询失败，后台最多自动重试 3 次。
- 无网络或接口失败时，必须允许用户保存单词，不得阻断收词。
- 第三方词典的授权、缓存和展示方式必须符合其许可条款。

建议接口：

```csharp
public interface IDictionaryProvider
{
    Task<DictionaryEntry?> LookupAsync(
        string term,
        string language,
        CancellationToken cancellationToken);
}
```

## 7.3 上下文与遇见记录

每次收词都创建一条遇见记录；字段为空也允许保存。

| 字段 | 必须 | 说明 |
|---|---|---|
| 单词 ID | 是 | 关联主记录 |
| 遇见时间 | 是 | 使用 UTC 存储，本地时区显示 |
| 原句 | 否 | 最长 2,000 字符 |
| 来源应用 | 否 | 例如 Chrome、Edge、Adobe Acrobat |
| 来源标题 | 否 | 网页标题或文件名 |
| 来源地址 | 否 | URL 或文件路径 |
| 用户备注 | 否 | 最长 2,000 字符 |

隐私要求：MVP 不持续监听剪贴板；仅在用户粘贴或触发快捷键时读取一次。来源采集失败不得弹出阻断性错误。

## 7.4 单词库

### 7.4.1 列表字段

- 单词
- 首条释义
- 熟练度徽标
- 掌握度
- 用户标记
- 遇见次数
- 最后复习时间
- 下次复习时间
- 标签

### 7.4.2 搜索与筛选

- 支持按单词、中文释义和备注模糊搜索。
- 支持按 L0～L5 多选筛选。
- 支持按“到期、待抽查、重点、易错、暂停学习”筛选。
- 支持按标签筛选。
- 支持按添加时间、最近遇见、掌握度、遇见次数和下次复习时间排序。
- 搜索结果应在 10,000 条本地单词数据下于 300 ms 内返回。

### 7.4.3 详情页操作

- 编辑展示词、音标、释义、例句和备注。
- 查看全部遇见记录和复习历史。
- 添加或删除标签。
- 设置用户自评和用户标记。
- 暂停/恢复学习。
- 手动重新查询词典。
- 删除单词。删除前必须二次确认；删除主记录时级联删除遇见与复习记录。

## 8. 熟练度系统

## 8.1 等级定义

| 等级 | 名称 | 默认颜色 | 定义 |
|---|---|---|---|
| L0 | 未学习 | 灰 | 已收录但没有有效复习事件 |
| L1 | 生词 | 红 | 有复习记录但规则评估分数低于 25 |
| L2 | 模糊 | 橙 | 有印象但回忆不稳定 |
| L3 | 基本掌握 | 黄 | 规则评估分数至少 45，但尚未达到L4时间和证据条件 |
| L4 | 熟练 | 绿 | 分数至少70、稳定性至少7天、成功回忆证据至少3点，且首次复习后至少经过7天 |
| L5 | 稳定掌握 | 蓝 | 分数至少88、稳定性至少21天、成功回忆证据至少5点，且首次复习后至少经过21天 |

界面必须同时显示文字或等级，不能只显示颜色。

## 8.2 四档反馈与复习间隔

MVP使用确定性算法，完整定义见 [ADR-006](../adr/ADR-006-熟练度与复习调度算法.md)。

| 反馈 | 代码 | 定义 | 证据点 | 首次间隔 |
|---|---|---|---:|---:|
| 完全不会 | AGAIN | 未想起、回答错误或必须看答案 | +0 | 10分钟 |
| 想起来了 | HARD | 勉强想起，耗时较长 | +0.5 | 1天 |
| 认识 | GOOD | 正确回忆主要含义 | +1 | 2天 |
| 太简单 | EASY | 快速、完整回忆 | +1.5 | 4天 |

后续间隔：AGAIN固定10分钟；HARD为`max(1天,旧间隔×1.2)`；GOOD为`max(2天,旧间隔×2.0)`；EASY为`max(4天,旧间隔×2.0)`；最大180天。MVP不加入随机扰动。

## 8.3 掌握度更新

每个学习项保存稳定性估计 `stability_days`、证据点、遗忘次数和复习事件。展示分数使用：

```text
mastery_score = clamp(
    round(stability_days × 2 + min(evidence_points, 5) × 8 - lapse_count × 6),
    0,
    100
)
```

证据点以整数十分位保存，避免浮点累计误差。系统必须记录复习前后状态、实际经过时间、计划到期时间和算法版本。

## 8.4 等级判定

系统每次复习后按以下顺序判定：

1. 无复习记录：L0。
2. 分数小于25：L1。
3. 分数25～44：L2。
4. 分数至少45但未满足L4条件：L3。
5. 分数至少70、稳定性至少7天、证据点至少3、首次复习后至少7天：L4。
6. 分数至少88、稳定性至少21天、证据点至少5、首次复习后至少21天：L5。

AGAIN不会提高分数、稳定性或等级。L4收到AGAIN后等级不得高于L3；L5收到AGAIN后等级不得高于L4。连续两次AGAIN额外扣8分。超过下次复习时间30天未复习时显示“待抽查”，不自动降级。

### 8.4.1 降级规则

- L5 收到一次 AGAIN：降为 L4，掌握度按公式下降。
- L4 收到一次 AGAIN：降为不高于 L3。
- 任意等级连续两次收到 AGAIN：在公式结果基础上再扣 8 分，并至少下降一级。
- 长期未复习不直接降级；超过 `next_review_at` 30 天后标记“待抽查”，并提高队列优先级。

## 8.5 用户自评与系统熟练度

用户自评取值：陌生、模糊、熟悉、已掌握。用户自评与系统等级分别保存。

- 用户设置“已掌握”时，系统不得直接设为 L5。
- 若系统未满足 L5 条件，显示“用户认为已掌握 · 系统待抽查”。
- 用户可选择“暂停学习”；暂停后不进入自动队列，但仍保留全部数据。
- 用户可以手动重置学习进度。该操作必须二次确认，并保留单词及遇见记录，只清除复习事件和系统评分。

## 8.6 用户标记

MVP 支持多选标记：

- 重点
- 易错
- 高频
- 必须掌握
- 暂不学习

“高频”可由用户手动添加；当 30 天内遇见次数达到 3 次时，系统建议添加，但不自动修改用户标记。

## 9. 每日任务与队列

## 9.1 用户配置

默认设置：

- 每日新词目标：20 个。
- 每日复习软目标：50 个。
- 每日复习不设硬上限。
- 会话默认长度：20 个。
- 用户可将新词目标设置为 0～200，将复习软目标设置为 10～500。

“软目标”用于进度展示，不阻止用户继续复习，也不丢弃到期词。

## 9.2 队列优先级

按以下优先级从高到低排列：

1. 当天 AGAIN 后等待重试的单词。
2. 已逾期且标记“必须掌握”或“易错”的单词。
3. 其他到期词，逾期越久越靠前。
4. L4/L5 的待抽查词。
5. 近 30 天遇见至少 3 次且低于 L4 的词。
6. 今日新词。
7. 未到期的额外练习词。

相同优先级内，先按逾期时长降序，再按掌握度升序排列。

系统在用户进入“今日”或开始一次复习会话时创建任务快照。快照中的任务项在本次会话内不重复，包含 `session_id`、`queue_reason`、创建时间和计划数量。新收词、AGAIN重试和“再学10个”作为会话外新增项或独立会话处理，不修改已开始会话的原始计划分母。

今日摘要中的分类必须互斥：

1. AGAIN重试。
2. 普通到期复习。
3. 待抽查。
4. 今日新词。
5. 额外练习。

“重点”“易错”“必须掌握”等是附加标记，不参与分类求和。

## 9.3 今日页面

页面必须显示：

```text
今日计划 68
AGAIN重试 4 · 到期复习 40 · 待抽查 5 · 新词 19
已完成 26 / 68
```

任务完成后显示：

- 本次复习数。
- GOOD/EASY 比例。

## 11. 进度面板

## 11.1 必须展示的指标

- 单词总数。
- L0～L5 数量和占比。
- 今日新增、今日复习、今日到期未完成。
- 最近 7/30/90 天新增量。
- 最近 7/30/90 天净掌握量。
- 成功回忆率：GOOD/EASY 数量 ÷ 有效复习事件数量；这是用户自评反馈统计，不是客观考试正确率。
- 到期完成率：统计期内按期完成的到期复习 ÷ 统计期内到期总数。
- 降级词数量。
- 待抽查词数量。
- 按标签统计的平均掌握度和 L4/L5 占比。

### 11.1.1 净掌握量定义

```text
净掌握量 = 统计期内 L0～L3 跨入 L4/L5 的次数 - L4/L5 跨回 L0～L3 的次数
```

L4与L5之间的互转不计入净掌握量；同时展示统计期内曾进入L4/L5的唯一学习项数量，避免把复习次数误认为掌握词数。

## 11.2 可视化

- 熟练度分布：六段横向条形图。
- 新增与复习趋势：按天折线图。
- 净掌握趋势：按天柱状图。
- 标签掌握情况：表格，不使用复杂雷达图。

所有图表必须提供数值文本或可访问性描述。

## 15. 推荐技术方案

MVP 推荐使用：

- .NET 10 LTS。
- C# + WPF。
- MVVM 架构。
- SQLite 本地数据库。
- Windows API 用于全局快捷键、前台窗口行为和系统托盘集成。
- 自包含 `win-x64` 应用加每用户 Windows 安装器发布；不要求目标机预装 .NET 运行时。

选择理由：本产品只面向 Windows，并高度依赖置顶窗口、全局快捷键、托盘和本地系统行为。WPF 是微软正式支持的 Windows 桌面 UI 技术；.NET 10 是 LTS 版本，支持期至 2028 年 11 月。实现时以微软官方 [.NET 桌面指南](https://learn.microsoft.com/en-us/dotnet/desktop/) 和 [.NET 发布与支持策略](https://learn.microsoft.com/en-us/dotnet/core/releases-and-support) 为准。

### 15.1 建议代码分层

```text
WordPin.App              WPF 页面、窗口、资源和 ViewModel
WordPin.Application      用例、队列、熟练度计算、接口定义
WordPin.Domain           实体、枚举、领域规则
WordPin.Infrastructure   SQLite、词典提供器、备份、Windows 集成
WordPin.Tests            单元测试和集成测试
```

熟练度计算必须放在独立、无 UI 依赖的服务中，并使用固定输入/输出，便于测试。

```csharp
public interface IMasteryCalculator
{
    ReviewOutcome Apply(WordLearningState state, ReviewInput input);
}
```

## 16. 数据备份、导入与导出

### 16.1 自动备份

- 应用运行期间每天创建一次备份，不依赖重启；长期驻留托盘时也必须执行。
- 保留最近 7 个每日备份和最近 4 个每周备份。
- 使用 SQLite Backup API 或 `VACUUM INTO` 创建一致快照，完整性检查通过后再原子替换备份目标。
- 恢复前自动备份当前数据库。
- 备份损坏时不得覆盖当前数据库。

### 16.2 CSV 导出字段

```text
term,definition,phonetic,level,score,user_rating,flags,tags,
encounter_count,created_at,last_review_at,next_review_at,note
```

CSV 使用 UTF-8 BOM，确保 Windows Excel 默认打开时中文正常显示。多值字段使用分号分隔。

### 16.3 JSON 导出

JSON 必须包含：版本号、导出时间、单词、释义、遇见记录、复习事件、标签、标记和非敏感设置。不得导出 API 密钥。

## 17. 非功能要求

### 17.1 性能

- 冷启动至托盘可用：目标小于 2 秒，普通办公电脑环境。
- 悬浮窗呼出：P95 小于 200 ms。
- 10,000 个单词下列表首次加载：小于 1 秒。
- 后台查询不得阻塞 UI 线程。
- 空闲时内存目标小于 200 MB。

### 17.2 可靠性

- 每次收词先提交本地数据库，再执行网络查询。
- 数据库写操作使用事务。
- 应用异常退出后，下次启动执行数据库完整性检查。
- 单实例运行；第二次启动时唤醒已有实例。
- 网络错误不得导致应用退出。

### 17.3 安全与隐私

- 默认不登录、不上传单词、原句、文件路径或剪贴板内容。
- API 密钥使用 Windows 凭据或受保护存储，不以明文写入配置文件。
- 来源文件路径只存本地。
- 日志不得记录完整剪贴板、完整原句、API 密钥或用户文件内容。
- 错误报告默认关闭；如后续加入，必须先脱敏并取得用户同意。

### 17.4 可访问性

- 所有功能可通过键盘操作。
- 文本与背景对比度至少满足 WCAG AA 的普通文本要求。
- 不只依靠颜色表达熟练度。
- 支持 Windows 125%～200% 显示缩放。
- 控件提供可被屏幕阅读器读取的名称。

## 18. 错误处理

| 场景 | 用户提示 | 系统行为 |
|---|---|---|
| 没有网络 | “已保存，联网后补充释义” | 保存占位记录并排队重试 |
| 词典无结果 | “未找到词典结果，可手动填写” | 保留单词并允许编辑 |
| 快捷键冲突 | “该快捷键已被其他程序占用” | 保持旧快捷键或要求重设 |
| 剪贴板为空 | “剪贴板中没有可识别的单词” | 聚焦输入框，不创建记录 |
| 输入为整段文字 | “检测到多个单词，请选择要收录的词” | MVP 可先要求用户缩短输入 |
| 数据库暂时锁定 | “保存失败，正在重试” | 自动重试 3 次，仍失败则保留内存草稿 |
| 发音播放失败 | “发音暂时无法播放” | 不影响其他功能 |
| 备份恢复失败 | “恢复失败，当前数据未被替换” | 保持原数据库 |

## 19. 分析事件与本地日志

MVP 不上传行为分析。为调试和进度统计，可在本地记录以下业务事件：

- `word_created`
- `word_encountered_again`
- `lookup_succeeded`
- `lookup_failed`
- `review_completed`
- `mastery_level_changed`
- `backup_created`
- `export_completed`

事件只保存必要字段和时间，不保存完整原句或剪贴板文本。产品统计直接从业务表计算，不依赖日志。

退出条件：上述 Windows 系统能力全部跑通，无阻断性风险。

### M1：收词闭环

- 悬浮窗。
- 手动/剪贴板收词。
- 词典查询和离线占位。
- 重复检测与遇见记录。
- 单词库基础页面。

退出条件：AT-001～AT-005 和 AT-201～AT-205 通过。

### M2：学习闭环

- 复习卡片。
- 掌握度与等级计算。
- 今日动态队列。
- 用户标记和暂停学习。

退出条件：AT-101～AT-107 通过，熟练度单元测试覆盖达标。

### M3：进度与数据安全

- 进度面板。
- 设置页。
- 自动备份、恢复、CSV/JSON 导出。
- 开机启动与通知。

退出条件：AT-301～AT-304 通过。

### M4：发布候选版

- 性能、可访问性、多显示器和缩放测试。
- 安装、升级、卸载测试。
- 修复高优先级缺陷。
- 完成隐私说明和应用内帮助。

## 23. 发布准入标准

同时满足以下条件才可发布 MVP：

- 全部 P0 功能完成。
- 全部验收测试通过。
- 无阻断级和严重级已知缺陷。
- 数据库迁移、备份、恢复和异常退出测试通过。
- Windows 11 24H2、25H2 和可用的26H1 x64各完成一轮核心回归。
- 100%、125%、150%、200% 缩放下无阻断性布局问题。
- 安装、覆盖升级、卸载均通过测试；卸载时不得默认删除用户词库。
- 隐私说明明确写出剪贴板、来源信息、网络查询和数据位置的行为。

## 24. MVP 之后的演进顺序

建议按以下顺序迭代：

1. 拼写和例句填空，形成“识别—回忆—运用”三维能力。
2. CSV 导入与 Anki 导出。
3. 浏览器来源自动采集。
4. OCR 框选识词。
5. 可选云同步。
6. AI 语境释义和个性化例句。

不建议在收词速度、数据可靠性和熟练度规则稳定之前加入 AI 或账号系统。

## 25. 需要产品负责人最终确认的默认项

以下内容已给出可直接开发的默认值，但在 UI 定稿前仍可调整：

- 产品正式名称和图标。
- 默认每日新词 20、复习软目标 50。
- 通知默认时间 20:00。
- 默认全局快捷键。
- 首个正式词典数据源及其许可和费用。
- 安装包形式与自动更新渠道。

除上述项目外，开发团队可直接按照本文档启动 M0 和 M1。
